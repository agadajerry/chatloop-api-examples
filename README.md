# ChatLoop HQ API examples

Complete server-side tutorials for sending WhatsApp messages, receiving replies through webhooks, and handling media and polls through ChatLoop HQ.

| Language | Guide | Runtime |
| --- | --- | --- |
| Node.js | [Order notifications](nodejs/README.md) | Node.js 22+ |
| Python | [Appointment reminders](python/README.md) | Python 3.10+; standard library only |
| PHP | [Enquiry confirmations](php/README.md) | PHP 8.1+ with cURL |

Start with a guide, connect a channel, set your environment variables, and run its example. Each configured run sends one real message. Credentials must remain on your server. Do not commit keys or private recipient information.

The examples handle HTTP failures and queued responses without automatic retries. API acceptance is not proof of recipient delivery. See the guides for troubleshooting and production considerations.

[Website](https://chatloophq.com) · [Developer guides](https://chatloophq.com/guides) · [API reference](https://chatloophq.com/docs)

## Validation

Examples are checked locally with mocked responses and syntax checks. Live sending requires your own connected channel and credentials; no live delivery claim is made here.
